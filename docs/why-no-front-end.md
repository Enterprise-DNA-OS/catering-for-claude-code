# Why no front end

The database holds the events and the working records. Claude Code, Codex, OpenCode or Cursor runs the same CLI. Read-only HTML views and printable documents come from those records.

A screen provides mobile entry, a calendar you can drag, live signature capture, offline delivery updates and payment checkout. This free version does not provide those. It has no sending or payment connection. Enterprise DNA builds the screens and connections your business needs as part of a customised version.

The local database needs one process at a time. For a team, use a shared Postgres database with permissions, protected credentials, backups and authenticated operators. The agent subscription and hosting are separate from the free code.
